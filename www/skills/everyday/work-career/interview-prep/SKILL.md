# Ilang araw bago
1. Pag-aralan ang kumpanya: ano ang ginagawa nila at ano ang kailangan sa posisyon.
2. Basahin ulit ang job post at i-match ang resume mo.
3. Maghanda ng 3 hanggang 5 kwento ng karanasan gamit ang **STAR**:

| Letra | Ibig sabihin |
|---|---|
| S | Situation: ang sitwasyon |
| T | Task: ang gawain mo |
| A | Action: ang ginawa mo |
| R | Result: ang kinalabasan |

4. Pag-ensayuhan ang mga karaniwang tanong: "Ikuwento mo ang sarili mo", "Ano ang lakas at kahinaan mo", "Bakit gusto mo ang trabahong ito".
5. Alamin ang karaniwang sahod sa ganitong posisyon bago pag-usapan ang inaasahan mong sahod.
6. Maghanda ng 2 hanggang 3 tanong para sa kanila.

# Araw ng interview
- Dumating nang 10 hanggang 15 minuto nang maaga (o mag-log in nang maaga kung online).
- Dalhin ang kopya ng resume at ID.
- Makinig muna bago sumagot. Maging tapat at tiyak.

# Pagkatapos
- Magpadala ng maikling thank-you email sa loob ng isang araw.
- Isulat ang mga natutunan para sa susunod.
