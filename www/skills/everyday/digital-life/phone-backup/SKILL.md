# Ang 3-2-1 na tuntunin
- **3** kopya ng mahalagang data
- **2** magkaibang uri ng lalagyan (phone at cloud, o phone at external drive)
- **1** kopya na nasa ibang lugar (cloud)

# Mga hakbang
1. **Larawan at video:** i-on ang cloud backup ng gallery o photos app na gamit mo, at kung kaya, magtabi rin ng kopya sa computer o external drive.
2. **Contacts:** siguraduhing naka-sync sa account (Google o Samsung).
3. **Chats:** i-on ang backup sa loob ng messaging app mismo.
4. **Apps at settings:** i-on ang built-in na backup ng phone.
5. **Subukan:** tingnan paminsan-minsan kung nasa cloud talaga ang mga file.

# Pitfalls
- Ang backup na hindi nasubukan ay hindi pa tiyak na gumagana.
- Kapag puno ang cloud storage, humihinto ang backup nang walang malinaw na abiso.
- Ilagay ang backup codes ng 2FA sa ligtas na lugar bago mag-reset o magpalit ng phone.
- verify: nagkakaiba ang lokasyon ng backup settings sa bawat brand ng phone.
