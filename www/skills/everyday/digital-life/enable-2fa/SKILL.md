# Ano ito
Dagdag na hakbang sa pag-login bukod sa password, para hindi basta mapasok ang account mo kahit nakuha ang password.

# Pagpili ng uri
| Uri | Seguridad | Paalala |
|---|---|---|
| Security key | pinakamataas | kailangan ng hardware key |
| Authenticator app | mataas | walang signal na kailangan |
| SMS code | mas mababa | mas madaling ma-hijack ang SIM |

# Mga hakbang
1. Unahin ang mga pinakamahalagang account: email, bangko at e-wallet, social media, cloud storage.
2. Sa Settings ng account, hanapin ang Security, tapos "Two-step verification" o "2FA".
3. Piliin ang authenticator app kung kaya. Sundin ang pag-scan ng QR code.
4. I-save ang **backup codes** sa ligtas na lugar (password manager o nakasulat at nakatago).
5. Subukang mag-login mula sa ibang device para ma-verify na gumagana.

# Pitfalls
- Huwag ibigay kaninuman ang 2FA code, kahit sino pa ang magpakilala.
- Kung mawala ang phone, kailangan mo ng backup codes. Huwag laktawan ang hakbang 4.
- verify: nagkakaiba ang pangalan ng mga menu sa bawat serbisyo.
