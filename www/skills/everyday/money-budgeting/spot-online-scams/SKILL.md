# Mga red flag
- [ ] Sobrang ganda ng alok (garantisadong tubo, libreng premyo, madaling malaking kita)
- [ ] Pinipilit kang magmadali o may deadline
- [ ] Hinihingi ang OTP, PIN, o password
- [ ] Hihingi ng bayad bago ibigay ang loan, premyo, o trabaho
- [ ] Ang kausap ay hindi mo makita o ma-verify
- [ ] Gusto kang ilipat sa ibang app o gumamit ng hindi karaniwang bayad (gift card, crypto)
- [ ] Ang link ay galing sa text o chat ng hindi mo kilala
- [ ] Bagong account ang nagpapakilalang bangko o kumpanya

# Bago magbayad
1. Huminto at huwag magmadali.
2. I-verify sa opisyal na website o numero ng kumpanya. Huwag gamitin ang numerong ibinigay sa chat.
3. Magtanong sa pamilya o kaibigan.
4. Kapag may isang red flag, ituring itong scam hangga't hindi napapatunayang hindi.

# Kung na-scam na
- Tawagan agad ang bangko o e-wallet para i-block ang account at transaksyon.
- Palitan ang mga password at i-enable ang 2FA.
- Mag-ipon ng ebidensya (screenshot, resibo, pangalan ng account).
- I-report sa awtoridad. verify: hanapin ang kasalukuyang opisyal na reporting channel sa bansa mo.
