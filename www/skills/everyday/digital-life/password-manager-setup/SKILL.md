# Mga hakbang
1. Pumili ng kilalang password manager na may magandang reputasyon. verify: basahin ang kasalukuyang reviews bago pumili.
2. Gumawa ng **master passphrase**: mga 4 o higit pang random na salita na madaling tandaan pero mahirap hulaan. Huwag gamitin kahit saan pa.
3. I-enable ang 2FA sa password manager mismo.
4. I-save ang recovery info sa ligtas na lugar. Kapag nakalimutan ang master passphrase, maaaring hindi na mabawi ang laman.
5. Unahin ang email, bangko, at e-wallet. Palitan ang mga password nila ng mahaba at random na gawa ng manager.
6. Isa-isang palitan ang mga password na paulit-ulit na ginagamit.
7. I-enable ang autofill sa phone at browser.

# Tips
- Isang unique na password sa bawat account.
- Ang email account ang pinaka-importante, dahil dito napupunta ang password reset ng lahat.

# Pitfalls
- Huwag ibahagi ang master passphrase.
- Huwag i-save ang password sa notes app o screenshot.
